Protocollo di Test

  1. A) Baseline: Avvia la cattura. Con NESSUN altro audio in riproduzione e tono OFF → il valore "RMS catturato" deve essere vicino a 0.
  2. B) Test auto-cattura: Accendi il tono 440 Hz. Osserva "Bin 440 Hz catturato": se SALE sopra ~40 = auto-cattura rilevata (rischio Larsen, backend NON utilizzabile). Se resta vicino a 0 = nessun loop, backend sicuro.
